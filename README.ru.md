# Инструменты Jetson Linux для Debian 13

[English](README.md) | **Русский**

Набор утилит и профилей плат для подготовки и прошивки NVIDIA Jetson Linux (L4T) с **хостовой системы Debian 13 (Trixie) x86_64**. Репозиторий автоматизирует исправления совместимости хоста, развёртывание L4T из архивов NVIDIA, установку профиля платы и отдельные операции прошивки.

> Это проект сообщества, не являющийся официальным продуктом NVIDIA. В примечаниях к Jetson Linux R36.5 NVIDIA указывает Ubuntu 20.04/22.04 x86_64 как поддерживаемую хостовую систему; совместимость с Debian 13 обеспечивается этим проектом и не является сертификацией NVIDIA. Перед прошивкой проверьте профиль платы и журнал его совместимости. См. [примечания NVIDIA к релизу](https://docs.nvidia.com/jetson/archives/r36.5/ReleaseNotes/Jetson_Linux_Release_Notes_r36.5.pdf).

## Состав проекта

- `setup_jetson.sh` — разворачивает согласованную пару архивов L4T и Sample Root Filesystem, применяет бинарные файлы NVIDIA, создаёт пользователя, устанавливает профиль платы, применяет исправления для Debian и настраивает UART autologin root.
- `setup_debian.sh` — устанавливает необходимые пакеты хоста и исправляет скрипты L4T для работы в Debian.
- `b_conf/` — профили плат, журналы совместимости, селектор профилей и утилиты прошивки.
- `b_conf/flash_jetson.sh` — показывает профили для версии JetPack и позволяет прошить полный образ, оба слота DTB или только rootfs.
- `b_conf/suppress_uefi_auth_warnings.sh` — необязательный патч исходников OP-TEE и сборка/установка образа для подавления двух предупреждений о тестовом UEFI-ключе.

## Требования

- Debian GNU/Linux 13 (Trixie), архитектура x86_64.
- Доступ к интернету и `sudo` для установки пакетов и подготовки L4T.
- Архивы NVIDIA Jetson Linux (L4T) и Sample Root Filesystem одной версии. Скачайте их с сайта NVIDIA и поместите рядом с `setup_jetson.sh`.
- Достаточно свободного места для архивов, распакованного BSP и rootfs. Проверьте доступное место командой `df -h`; требуемый объём зависит от релиза, размеров архивов и каталога развёртывания.
- Для прошивки — поддерживаемая плата Jetson, подключённая в режиме USB Recovery, и соответствующий профиль.

Установите зависимости хоста:

```bash
sudo apt-get update
sudo apt-get install -y \
  git pv tar bzip2 sudo \
  abootimg xmlstarlet gdisk parted cpio gzip binutils \
  sshpass openssh-client
```

`setup_debian.sh` проверяет наличие и устанавливает пакеты для исправления L4T из этого списка. `qemu-user-static` устанавливается автоматически только при входе в необязательный QEMU chroot; его также можно установить вручную. Полное руководство по пакетам, подготовке системы, профилям и прошивке находится в [документации](docs/USAGE.ru.md).

## Быстрый запуск

Склонируйте репозиторий и поместите подходящие архивы NVIDIA в его корневую папку. Укажите версию JetPack для выбора профиля и, при необходимости, точную версию архива L4T:

```bash
./setup_jetson.sh \
  --jetpack-version 6.2.3 \
  --version R36.5.2 \
  --board jetson-agx-orin-devkit-noeeprom \
  --skip-qemu
```

Для примера ожидаются файлы `Jetson_Linux_R36.5.2_aarch64.tbz2` и `Tegra_Linux_Sample-Root-Filesystem_R36.5.2_aarch64.tbz2`. Используйте точные обозначения версий из имён скачанных архивов. Если не указывать `--version`, скрипт выберет самую новую согласованную пару архивов.

Перед прошивкой проверьте профиль и переведите плату в режим USB Recovery:

```bash
./b_conf/flash_jetson.sh --list --jetpack-version 6.2.3
./b_conf/flash_jetson.sh \
  --board jetson-agx-orin-devkit-noeeprom \
  --mode full \
  --jetpack-version 6.2.3
```

Утилита запросит подтверждение перед записью. Параметр `--yes` предназначен для автоматического запуска и пропускает запрос подтверждения; используйте его, только если целевая плата и режим Recovery уже проверены.

## Профили плат

Профили находятся в `b_conf/`. Селектор ищет конфигурацию по приоритету: точная версия JetPack, семейство `major.minor.x`, семейство `major.x`, затем `common`. Каждый пакет — полная конфигурация профиля, пакеты между собой не объединяются. Для профиля следует добавить журнал `COMPATIBILITY.md`. См. [Добавление профиля платы](docs/USAGE.ru.md#добавление-профиля-платы) и [English guide](docs/USAGE.en.md#adding-a-board-profile).

Текущие профили `6.2.x` взяты из JetPack 6.2.3. Селектор семейства не означает, что проверены все выпуски 6.2. Перед прошивкой изучите журнал конкретного профиля.

## Безопасность

- `setup_jetson.sh` по умолчанию включает вход `root` без пароля через UART-консоль `ttyTCU0` для отладки. Если он не нужен, укажите `--no-root-uart-login`.
- Параметр `--force` удаляет существующую папку развёртывания `Linux_for_Tegra` перед повторной установкой. Сначала сохраните нужные данные.
- Необязательный патч OP-TEE скрывает только два предупреждения о тестовом ключе при стандартном уровне логирования T234. Он **не** включает защиту UEFI-переменных и не заменяет тестовый ключ.
